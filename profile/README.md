# macroexpand-1

Tooling for Common Lisp, built around the live image.

## Projects

| Project | What It Does |
|---|---|
| [splice](https://github.com/macroexpand-1/splice) | Safer patching of Common Lisp in production: hot-patching a running SBCL image as a reversible, monitored, auditable operation. |
| [seance](https://github.com/macroexpand-1/seance) | Live image handoff to LLMs: a SLY contrib that sends the symbol at point, its callers and callees, recent REPL evals, conditions and debugger state to Claude or a local model. |
